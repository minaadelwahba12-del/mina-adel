# دفتر حسابات المحل 📊

تطبيق سطح مكتب متكامل لإدارة حسابات المحل والمتاجر الصغيرة.

## المميزات ✨

- 📈 لوحة تحكم شاملة تعرض الأرباح والمبيعات
- 📄 إدارة الفواتير والمبيعات
- 📦 تتبع المخزون والمنتجات
- 👥 إدارة العملاء والموردين
- 💰 تسجيل النقدية والمدفوعات
- 📊 المصروفات والتكاليف
- 💾 حفظ البيانات محليًا على الجهاز
- 🎨 واجهة عربية جميلة وسهلة الاستخدام
- 🖥️ يعمل على Windows و Mac و Linux

## التثبيت

### المتطلبات
- Node.js 14 أو أحدث
- npm أو yarn

### خطوات التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/minaadelwahba12-del/mina-adel.git
cd mina-adel

# تثبيت الاعتماديات
npm install
```

## التطوير

لتشغيل التطبيق في وضع التطوير:

```bash
npm run electron-dev
```

هذا سيفتح نافذة Electron وتطبيق React معًا.

## البناء

لبناء التطبيق:

```bash
# بناء عام (لجميع الأنظمة)
npm run build

# بناء لـ Windows
npm run build-win

# بناء لـ macOS
npm run build-mac

# بناء لـ Linux
npm run build-linux
```

## الاستخدام

### لوحة التحكم
عرض سريع لأهم المعلومات:
- صافي الربح
- إجمالي المبيعات
- الأرباح الإجمالية
- المصروفات
- أحدث الفواتير
- المخزون المنخفض

### الفواتير
- إنشاء فواتير جديدة
- تتبع حالة التحصيل
- إدارة الأصناف والأسعار

### المخزون
- إضافة وتعديل المنتجات
- تتبع الكميات المتاحة
- حساب هامش الربح تلقائيًا

### العملاء والموردين
- إدارة بيانات العملاء والموردين
- تتبع الحسابات والمستحقات
- تسجيل المقبوضات والمدفوعات

### المصروفات
- تسجيل مصروفات المحل
- تصنيف المصروفات
- تتبع الإنفاق
